# @paperai/ui-acp

[English](README.md) | 中文

PaperAI 的 ACP 设置与会话控件。渠道目录仅开放 Codex 和 Claude，根据实际 provider 连接显示**已连接 / 未连接**。诊断握手通过是独立的历史观测，不会将渠道标记为已连接。

**一键检测**按钮并行检测渠道，不发送模型请求。渠道图标由产品品牌插件通过带键的 `paperai.acp.channel.mark` slot 提供。

设置页支持按渠道配置启动方式、只写凭据、默认 Agent/模型、代理、个人指令、模型收藏、显式检测和托管安装操作。账号、模型服务商和外部历史操作跟随适配器实际声明的能力。导入会打开已有的本地关联，或创建独立会话；失败时保留当前选择的会话及其草稿。

会话标题处展示当前连接所声明的模型与其他会话选项。搜索和收藏不改变实时模型目录；手工输入模型 ID 会交给 provider 验证。权限类选项仍由现有权限选择器管理。

插件读取共享设置镜像，复用 workbench 挂载的生成式 PaperAI Remote。控制器负责异步操作、过期响应拦截和会话作用域销毁，不另建磁盘设置存储或 Remote 挂载。[ACP 服务](../../paperai/agent-acp/README.zh.md)负责进程、权限、历史与协议语义。

## 模型体验

### ACP 设置

#### 模型看到什么

打开设置、查看状态和检测渠道不添加模型输入。保存的 `language` 和 `personalPrompt` 指令由 ACP 服务应用；选定模型与选项影响后续 provider 请求。

#### Token 影响

UI 不添加 prompt token。ACP 服务拥有实际发送的文本和工具。

#### KV Cache 影响

UI 不持有 provider 缓存。应用不同模型或 prompt 偏好可能改变后续请求前缀。

## 已知限制与后续工作

- 目录仅开放 Codex 和 Claude，不启用其他 ACP 模板或自定义渠道身份。
- 账号和外部历史按钮依赖适配器实际能力；仅支持 CLI 的登录方式显示原生命令。
- SSH 执行需要显式配置远程 POSIX 主机，目录会区分该主机与本地 PaperAI 项目。
