# @paperai/ui-workbench

[English](README.md) | 中文

基于 DSH 插件和 slot 的 PaperAI 浏览器工作台。左侧显示项目和受管理的 Word 文档；文档默认进入写作模式，可明确切换到右侧 Agent 协作。写作模式和缩放按 Session 记忆。产品通过 `ctx.layout.configure` 安装 `PAPERAI_LAYOUT_CONFIG`：`detailsPosition: start`、`centerMin: 360`、`detailsMin: 480`、`detailsDefault: 860`、`detailsMax: 1280`，允许当前空白 Session 显示文档，两栏无法并排时聚焦文档。进入协作、让 Agent 修复检查问题或引用选区，都会关闭文档面板并显示对话，空间足够时文档仍在旁边。

本插件贡献文档列表和项目体检、项目起始页、模板设置页和 `paperai` 文档视图。Workspace 导航、对话、权限控制和模型选择仍由 DSH 提供。注册通过 `slots.inject()` 跟随 slot 声明者的生命周期。颜色和共享控件来自 DSH。

起始页创建或打开项目目录，以模板、文档数和最近编辑时间标识项目，列出已追踪文档及其类型，并通过一个菜单从项目模板格式新建或自由导入 Word。同名文档显示文件名和文档 id 简写，提示中保留完整工作路径和标题。模板选择由用户主动打开；对话框与设置页共用模板库存储，替换前说明影响，移除格式或模板集前确认。[Host 服务](../../paperai/workbench-service/README.zh.md)拥有导入限制、模板语义和文档操作。

文档视图在 shadow root 中渲染经过净化的派生 HTML，保留嵌入式位图。单一编辑宿主保留浏览器原生跨段选区。只有带有提供方 `data-path` 的块才按文本、单元格归属和阅读顺序参与匹配。未映射子树显式只读；拒绝映射块外输入、跨原始块边缘删除及拖放修改，同一原始块内的空草稿段落仍可合并。被拒绝且不可取消的组合输入会恢复预览节点，保留草稿与历史记录的节点引用。没有地址的页眉、页脚不会消耗同名正文的匹配项；未匹配或只读的单元格不能指向正文段落。浏览器与 Host 都保护包含复杂对象的段落，拒绝可能破坏对象的文字或 run 重建。

常驻工具栏提供保存、草稿撤销和重做、字体、磅值字号、加粗、倾斜、下划线、清除字符格式、段落样式、对齐、左缩进、行距及查找。字符状态区分继承、显式设置和混合值；保留的选区支持跨映射块格式操作，折叠光标处的格式作用于后续输入。Enter 拆分普通正文段落，Shift+Enter 插入软换行，粘贴换行形成结构草稿；组合输入按一组撤销。草稿始终定位到原始节点，将段落、run 和布局交给一次事务提交。Ctrl/Cmd+S 或 Ctrl/Cmd+Enter 保存，Ctrl/Cmd+Z 及重做处理本地草稿，Escape 放弃当前块的草稿。

模板、格式检查和版本面板一次打开一个，位于页面旁并临时占用对话空间，关闭时恢复焦点；窄栏内面板上下排列。版本比较标记能够定位的文字变化，无法定位的变化单独列出，不猜测位置。已记录的格式操作另有计数，不表示完整的格式差异。比较期间块保持只读。恢复需确认并创建新版本，不代替草稿撤销。导出使用已保存文档，有草稿时不可导出，区分未做交付检查的草稿与正式交付检查，并显示输出路径或阻塞问题。

稳定的状态栏说明内存草稿、保存中、完成和操作失败。缩放支持适合页宽及 50–200%，改变缩放时保留相对滚动位置；预览明确说明最终分页以 Word 为准。若因工作文件在 PaperAI 之外被修改而拒绝提交，会提示把该文件记为一个新版本并重新打开文档、保留草稿；项目体检对它标出的每份文档提供同样的操作。

`Config.retainedPreviews` 为正整数，默认 `2`，包含当前预览。最近预览保留 DOM、滚动位置和段落草稿。淘汰预览时释放较重的渲染内容，轻量草稿与滚动偏移保留至插件卸载。文档变更使后台预览失效，重新连接会读取已加载的投影。草稿保留基准 revision：较新的版本即使文字未变也使草稿进入冲突，防止覆盖仅格式更新。冲突草稿保留供复制或放弃。已有未保存草稿时不能新建文档；若在导入或从模板创建期间开始写草稿或切换文档，当前视图会保留，完成后的文档加入项目列表。

选择 Word 中已映射的文字会显示“交给 Agent”。点击后插入可移除输入引用，包含文档 id、路径、revision、当前提交、块 id 和精确文字。序列化内容在异步发送前冻结，切换文档不会改变引用对象。既有引用 codec 处理剪贴板持久化、移除和消息序列化。格式检查面板的修复操作会将请求追加到已有输入之后，保留图片和引用，并展开会话供用户检查。这些操作不会发送消息。

项目体检首先执行只读扫描；用户恢复前，方案预览明确显示缺失的工作文件和准确版本。[提交服务恢复流程](../../paperai/commit-service/README.zh.md)负责校验和发布。

插件先挂载生成的 `@paperai/workbench-service/remote` descriptor，再注册 UI。传输类型来自 `@paperai/workbench-service/types`。不依赖 React 的控制器拥有浏览器状态、拒绝过期回执，并在卸载时释放订阅和未完成的读取。

打开、导入或创建文档时，沿用当前项目中已选中的 Session，包括已经开始 Agent 对话的会话。连接其他项目时才在目标项目中解析 Session。再次打开当前文档会保留草稿。

已发送的 Word 引用显示选中文字，来源信息可按需展开。序列化消息以文档标题开头；复制结果和会话日志保留完整来源。项目体检显示本地化问题名称，路径分隔符统一为正斜线。

## 模型体验

### 显式 Word 上下文

#### 模型看到的内容

只有用户保留并提交的引用才进入普通 `user/message` 内容。每条引用包含精确文字及文档、版本来源，因此 DSH 日志无需读取当前预览就能重建上下文。

#### Token 影响

提交选区会将文字和来源加入该消息；预览和诊断不增加 token。

#### KV Cache 影响

正常追加用户消息；诊断和导航不改变请求前缀。

## 已知限制与后续工作

- DOCX 始终是权威正文；浏览器 HTML 和草稿不是第二份文档存储。
- 未映射内容、复杂对象段落和表格内结构变化需要 Word 或受支持的 Agent、引擎操作。浏览器不能编辑尚未建模的 run 属性。
- 跨不同原始节点的替换或删除受到保护；可跨这些节点选择文字进行格式操作或引用。尚不提供详细格式差异或精确 Word 分页。
- 预览缓存和草稿属于浏览器生命周期状态，刷新页面后不恢复。
- 缓存模型描述此前初始化的情况，只有已连接适配器才能决定当前选择。
