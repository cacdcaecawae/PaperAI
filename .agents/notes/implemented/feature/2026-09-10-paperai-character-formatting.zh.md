# Agent Note: 从页面把字符格式写进 DOCX

Status: implemented

[English](2026-09-10-paperai-character-formatting.md) | 中文

## 问题

块可以直接书写，但只能写纯文本。浏览器的每次提交都编译成 `set <段落> --prop text=`，OfficeCLI 会把整段替换为一个隐式 run，因此带加粗开头或红色短语的段落，只要有人改一个错字，这些格式就全没了。产品里没有任何地方能加粗或改字号，而写作者要的正是这个。

## 决策

`replace-text` 新增可选的 `runs`：把块的文字按字符格式的变化切分，每个 run 只声明它相对本块的覆盖（`bold`、`italic`、`underline`、以磅为单位的 `size`、`color`）。同一形状贯穿整条路径——domain 的 `DocumentTextRun`、引擎契约的 `EngineTextRun`、工作台传输的 `PaperAIDocumentTextRun`——因为这些层本就各自重述变更而非共享类型。带 runs 时，文字未变的提交也被接受，于是单独的排版也是一个版本，其消息读作"排版"而非"修改"。runs 的文字拼接必须与变更的 `nextText` 完全一致，由提交服务校验。

OfficeCLI 重建该段落：设置段落文字，在 `r[1]` 上声明第一个 run 的覆盖，再依次追加其余 run。这是多次操作，因此 runs 作为一次 `batch` 调用发出，而不是每次一个进程往返——常驻状态下单条命令约 380 毫秒，三个 run 的段落否则要付四次。纯文本仍走一直以来的单条 `set`，所以不改格式的提交开销与从前完全相同。

浏览器按 Word 存储的方式读取一个块。Host 本就把每个 run 渲染成带内联样式的 `<span>`，因此 `runsOf` 遍历块内的文本节点，将各自的解析样式与块自身比较，并合并读起来相同的相邻部分；没有覆盖的块序列化为一个 run，按纯文本提交。选中的文字通过包一层声明该变化的 span 来格式化，并清除其内部的同名声明，使读到的是新值；重复的变化会清掉上一次留下的包装，而不是叠加互相打架的值。块现在是 `contenteditable` 而非 `plaintext-only`，因此粘贴被拦截、只按纯文本插入。格式控件放在本就提供"交给 Agent"的选区栏里，Ctrl/Cmd+B、I、U 从键盘做同样的事。

## 考虑过的替代方案

**保留纯文本路径，只加段落级加粗。** OfficeCLI 的段落级 `bold` 会一次作用于所有 run，无法表达句中的一个加粗短语；而能表达它的 run 重建同时修好了纯文本路径本就存在的格式丢失，所以那一小步做完还是要推翻。

**只发送写作者动过的 run，按原始序号寻址。** 这能保住 PaperAI 未建模的所有属性，但拆分与合并会让寻址在引擎里变成一个 diff 问题。从页面重建是一条规则；有风险的属性正是渲染预览未表达的那些，而此前的行为把它们全都丢掉了。

**用内联样式而非解析样式读取 run。** Host 的样式表也会按规则设置字符属性（页眉页脚、目录链接），只读内联会误判。这里用解析样式没有代价：页面的缩放不会缩放报告出的字号，磅值可以直接由像素换算。

**`document.execCommand`。** 它免费处理区间的拆分与合并，但在 shadow 树中的行为没有规范，且已废弃；包装并清除的规则约二十行，只做一件事。

## 测试

单元覆盖：把块读成 runs，包含关闭本块自身格式的 run；比较 runs 使未改动的块不留草稿；把 runs 写回为 span；把带格式的提交画进已在屏幕上的预览；run 重建产生的 OfficeCLI batch，以及纯文本保留的单条命令；提交服务接受仅排版的修改并拒绝拼接与变更文字不符的 runs；页面把加粗并改过字号的选区报告为 runs。一项浏览器测试对一个段落加粗并改字号、保存，再从重新渲染的预览里读回 run 属性，从而在真实文档上验证 OfficeCLI 的 batch。

## 后果

段落已有的字符格式现在能在改动其文字后保留下来，此前不能。格式化一个 run 会在该 run 上以磅声明字号，因此后续的模板改动不再移动它。重建追加的 run 继承段落标记的属性而非第一个 run 的属性，因此带东亚字体提示的段落，其追加的 run 可能丢掉该提示；渲染预览未表达的属性——字间距、逐 run 的字体——完全不携带。给 Remote 请求新增字段必须通过 host 构建重新生成 typert 描述符：生成的客户端 schema 会静默丢弃未声明的字段，Host 随后会把请求判为无操作而拒绝。
