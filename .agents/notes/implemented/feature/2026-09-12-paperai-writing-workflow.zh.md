# Agent Note: PaperAI 写作流程与结构草稿

Status: implemented

[English](2026-09-12-paperai-writing-workflow.md) | 中文

## 问题

页面编辑器拦截普通 Enter，仅在选中文字后显示格式控件，也无法通过提交服务保留段落结构。空白对话占用文档空间，项目模板提示自动弹出，布局选择在刷新后消失，弹窗焦点可以落到背后。刷新草稿时只比较文字，可能覆盖外部格式修改。这些问题在项目、文档、设置和 agent（智能体）协作之间打断了同一条写作流程。

## 决策

Working DOCX 仍是真源。浏览器草稿附着于原始索引节点，可以携带替换段落、字符 run 和段落布局。提交服务校验基准 revision，并通过候选文件与版本事务发布。[Word 编辑保留决策](../bug-fix/2026-09-13-paperai-word-edit-preservation.zh.md)拥有原节点绑定、按序引擎写入、元数据保留和复杂段内对象保护。提交流程重新索引保存后的 DOCX。

常驻工具栏针对保留的光标或选区操作，并支持本地草稿历史。字符状态区分混合、继承和显式格式。Enter、软换行、纯文本粘贴及组合输入都使用同一草稿流程。较新的文档 revision 即使文字仍相同，也使既有草稿进入冲突，保护外部格式修改。恢复历史版本需要单独确认并创建新版本。内存草稿明确说明刷新后丢失。

文档默认进入写作模式；协作由用户明确选择，也会在把 Word 引用加入输入框时进入。既有布局服务持久化偏好宽度与侧栏收起选择，临时面板可见性不持久化。Session 范围的工作台存储保留写作和缩放偏好。辅助面板一次打开一个并恢复焦点，窄栏内面板沿阅读方向排列。模板由用户主动打开，破坏性模板操作说明影响，导出等待草稿保存，状态栏区分保存与其他操作失败。版本比较统计已记录的仅格式操作，不声称提供详细格式差异。

导航、对话、批准、工具展示和共享 UI 由 DSH 拥有。弹窗通过已安装的 `focus-trap` 依赖管理焦点，涵盖 portal 菜单；嵌套 Escape 只关闭当前活动区域。ACP（Agent Client Protocol）驱动切换清除旧模型选项，错误保留重试路径，设置保存失败保留输入。两个模型选项入口都刷新共享模型目录。模型选项继续来自已连接驱动，权限默认值不变。MCP 服务器构造明确校验三个数值限制：解析后的配置还包含路由和服务器名称字符串，不能使已认证的初始化失败。

初始会话标题使用首条提示词的第一个非空可见行。展开的引用保留在日志消息和模型输入中。ACP 标题若只是在规范化后完整重复多行提示词，就保留已有标题，避免会话标题显示引用元数据。单行提示词仍可用作原生标题，用户固定的标题继续优先。

本决策部分取代[界面重构](2026-09-03-paperai-ui-overhaul.zh.md)和[极简工作台](2026-09-09-paperai-minimal-workbench-and-outside-edits.zh.md)中关于模板提示、编辑命令、默认聚焦与面板行为的决策，并取代[字符格式](2026-09-10-paperai-character-formatting.zh.md)中的工具栏位置与 run 属性范围。其插件归属、模板模型、常驻引擎生命周期、版本发布决策继续有效；run 继承遵循 Word 编辑保留决策。[会话标题决策](2026-07-21-log-backed-session-titles.zh.md)保留其归属与时序规则；回退标题先选择一个可见行，再应用词数与字节限制。

## 考虑过的替代方案

**独立的富文本编辑器文档存储。** 它需要独立寻址和 DOCX 序列化。原始节点草稿扩展现有事务，不使浏览器 HTML 成为权威正文。

**持久化全部布局状态。** 恢复临时比较面板或聚焦要求可能隐藏新选中的对话。仅持久化用户偏好，文档内容和临时区域遵循原有生命周期。

**文字相同即视为草稿基准未变。** 文字相等无法检测字体、布局或嵌入对象的变化。revision 检查有意要求在出现任何更新版本后处理草稿。

**只用原生 dialog。** DSH 既有菜单 portal 到 document body，模态顶层会使这些控件不可交互。一个共享焦点约束支持这些消费方，避免每页单独实现对话框。

## 测试

组件和控制器测试覆盖面板偏好、键盘调宽、弹窗焦点、portal 菜单、驱动切换、重试、结构输入、组合输入、草稿历史、格式、冲突和版本操作。Host 测试覆盖事务校验和操作计数。[Word 编辑保留测试](../bug-fix/2026-09-13-paperai-word-edit-preservation.zh.md#word-edit-tests)覆盖原生模板与 MCP 读回。组装后的 PaperAI 浏览器场景覆盖导航、权限、编辑、检查、版本、导出及视口、主题、语言布局，包括 Agent 切换延迟期间的空模型目录。

## 后果

单一浏览器编辑区域允许原生选区跨越段落。草稿仍由原始索引块拥有，未索引内容与跨块文字变更保持受保护。

浏览器格式操作涵盖已表达的字符值，引擎保留其他 Word 元数据。编辑命令先采集全部变更块，再发布同步存储更新，避免订阅者回涂尚未采集的块。引用选区或准备格式修复会追加到现有输入框草稿，并保留附件。

PaperAI CI 命令纳入共享 primitives、会话标题和连接 fixture 测试，因为这些行为都参与组装后的写作工作流。

普通正文段落可以拆分和排版，文档权威来源不变。尚不支持的富内容段落和表格结构编辑仍受保护，浏览器不能编辑全部 Word run 属性。草稿及撤销历史是临时状态，尚无详细格式差异，预览分页不等于最终 Word 分页。[工作台 README](../../../../packages/client/ui-paperai-workbench/README.zh.md)拥有当前命令与生命周期细节。
