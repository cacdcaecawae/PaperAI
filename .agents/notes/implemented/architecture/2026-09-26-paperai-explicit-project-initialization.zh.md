# Agent Note: PaperAI 项目初始化要求明确操作

Status: implemented

[English](2026-09-26-paperai-explicit-project-initialization.md) | 中文

## Problem

PaperAI 共享 DSH 的工作区注册表。工作区记录代表导航目标，不代表允许向其中写入 PaperAI 目录、Git 元数据或 Agent 指令。通过浏览器订阅或读取操作初始化项目会改动无关仓库，还可能重新创建已经移动的目录。

## Decision

[工作台服务](../../../../packages/paperai/workbench-service/README.zh.md) 负责浏览器操作的初始化。选择项目模板（包括不用模板）、导入文档或从模板新建文档可以初始化尚未登记的项目。这些操作首先要求工作区根路径是已存在的目录。该要求在串行化的初始化操作内部执行，而不仅是预先检查：服务以 `existingRoot: true` 调用 `paperProjects.create`，缺失或非目录的根路径会被拒绝，创建项目子目录的过程也从不重新创建中途消失的根目录。已有项目中工作台随后自己的写入（上传暂存、文档导入暂存、导出）同样在根目录之下逐级创建目录，因此“根目录必须存在”始终是这些写入操作本身的一部分，而不是请求早先做过的一次检查。随后提交的快照与候选目录由 commit-service 创建，不在这一保证范围内。已存在的项目直接复用，不再次运行目录和章程准备；工作区被删除后又为同一目录重新登记的项目也是如此：`paperProjects.create` 按规范根路径找到并接管它，只改写记录中的工作区关联，`PAPERAI.md`、`AGENTS.md`、`CLAUDE.md` 和 Git 元数据都不受影响。

共享 API 网关同样要求指定工作区的 `session.create` 请求具有已存在的目录。会话初始化在创建或恢复 Agent 之前立即检查根路径，取代普通 `cwd` 请求仍保留的递归建目录，因此启动时自动选择会话不能重新创建已删除的工作区。这一要求随同一 Session id 的共享创建过程生效：指定工作区的请求并入同一 id 尚在进行的普通 `cwd` 请求时，该创建过程同样不会重新创建根目录。

读取概览和打开文档从不创建项目。未登记的工作区具有只读概览，包含工作区标题、尚未决定的模板和空文档列表。现有起始页控件允许用户选择模板或导入文档。打开文档及项目诊断要求项目已经存在。读取操作按工作区 id 或规范根路径查找项目：删除工作区后又为同一目录重新登记时，新登记会获得新的 id，项目及其文档和模板决定依然可见，打开或编辑其中的文档时返回的也是新的工作区 id。只有明确操作才会改写记录中的工作区关联。编辑在提交前就确定这一关联，因此持久写入之后返回的投影不依赖任何可能失败的查找。浏览器只为已挂载的视图请求概览，不初始化整个工作区列表。

## Alternatives considered

**只删除启动订阅。** 已挂载视图和直接 Remote 调用仍然会读取概览，因此 UI 的触发时机不能授权文件系统修改。

**为 `paperProjects` 增加单独的 `adopt` 方法。** 该方法的唯一调用方是工作台，而项目服务已经定义了唯一的“创建或接管”操作，不存在独立的“打开项目”操作。因此由 `create` 自己接管已有记录的目录，目录布局、章程和 Git 工作只对尚无项目记录的目录执行。接管在这一串行操作内部检查根路径仍是目录，因此被普通文件取代的根路径绝不会被发布。

**分离工作区注册表或增加初始化标记。** 保证读取安全不需要这两种机制。共享注册表仍然方便导航，现有明确的文档和模板操作已经表达所需意图，无需另一份持久化状态。

## Consequences

仅选择或查看目录不会安装 PaperAI 指令。目录不存在时会报错，目录保持缺失状态。已有项目和无关 DSH 工作区可以共存于同一列表。已经写入的项目文件不会自动删除，因为其中可能包含用户修改。明确操作之前已运行的原生 DSH 会话会在下一次模型请求中收到新安装的写作章程：`agent-instructions` 在每个进入的步骤比较可见基线中的文件（包括根目录的 `AGENTS.md` 和 `CLAUDE.md`），并把替换内容作为记录在会话日志中的消息追加，文档变更后改写章程也走同一路径。

验证覆盖只读 Remote 调用、明确初始化、缺失及非目录根路径（包括重新登记后被普通文件取代的根路径，以及经由父目录别名访问的已删除记录根路径）、初始化、会话创建或后续写入途中被删除的根路径、项目目录重新登记工作区后的读取、明确操作以及提交后根路径查找失败的编辑、项目根路径不一致，以及无关工作区的浏览器启动和视图挂载。无密钥浏览器快照记录明确选择模板前后可用的模板和导入控件。
