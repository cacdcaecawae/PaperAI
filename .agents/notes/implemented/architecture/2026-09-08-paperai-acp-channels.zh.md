# Agent Note: PaperAI ACP channels and provider-owned sessions

Status: implemented

[English](2026-09-08-paperai-acp-channels.md) | 中文

## 问题

渠道总览必须区分安装状态、过去成功的握手和当前打开的会话。ACP 进程还拥有外部历史、选项、工具和凭据；将它们与 DSH 本地状态混同，可能丢失上下文或向错误项目授予权限。

## 决策

PaperAI 通过统一的 ACP 实现和设置目录开放 Codex 与 Claude，拒绝其他渠道身份。DSH 原生循环与其他 profile 保留各自组合。Provider 定义向预设注册表贡献精确工厂路由；不能将这种路由复制成普通文件预设，因为空组合无法重现外部循环。

本决策部分取代[产品 profile 决策](2026-08-28-paperai-product-profile.zh.md)中的初始 PaperAI 渠道名单。[Agentero 采纳决策](2026-09-05-paperai-agentero-adoption.zh.md)继续拥有文档导航与草稿保留规则，本记录拥有扩展后的 ACP 目录和生命周期。[模型选项决策](../feature/2026-09-02-acp-model-effort-switch-selection.zh.md)继续保留事务与日志重建依据。

## 所有权

检测结果与会话使用相互独立。已发布会话持有 ACP 连接时，目录将渠道标记为正在使用；未使用不代表不可用。每个会话拥有独立进程，因此 Codex 与 Claude 可同时运行并分别关闭。无法获取 Host 观测时，使用情况未知。检测与管理连接不获得项目文件、权限或 PaperAI MCP 描述符。启动有期限和取消机制；更新的选择会取消旧启动，同时保留浏览器会话绑定，直到 Host 完成替换收尾。

共享设置镜像仍是浏览器唯一设置读取者。凭据通过路径变更修改，其他字段编辑不会抹去已脱敏的值。模型收藏和默认设置属于渠道，协商选项与计划属于单个会话。

已有的顶层 Codex 与 Claude 设置在用户设置节内迁移，新格式字段优先，旧键在同一次带修订校验的写入中移除。迁移在设置节注册后执行，并在设置变更时重试。编辑器写入会原子移除所编辑字段的旧副本，防止失败的迁移恢复已清除的凭据。默认值属于可选偏好：自定义模型需要提供方接受，不可用选项会告警，被拒绝的选择只有确认恢复成功才继续。传输失败与权限同步失败仍会终止启动。启动修订键不包含显示名称、语言和个人指令，因为这些字段不会改变 ACP 握手。

外部历史导入到新的本地会话，重放先写入独立暂存日志，通过校验后发布，并关联 provider 身份与执行主机。已有的关联会被复用。本地分叉不能复用父会话的外部身份或假造截断位置。原生 close 释放连接；显式删除外部历史需要单独校验能力，并拒绝仍在本地活动的关联。

文件与终端请求保留所属会话及取消信号，返回 provider 的结果、额外 prompt 上下文和回答均入日志。工具进度更新已有调用；纯展示函数复用通用、diff、终端卡片，不注册可执行的 DSH 工具。图片进入附件服务；没有标准展示块的媒体保留原始数据，并明确提示当前展示限制。

工具进度通过可配置的定时器合并输出更新，使运行中的命令保持可见，同时避免逐次记录不断增长的前缀。状态变化和回合终止（包括取消）会立即写入；终止时先清除定时器，再处理已接受的更新。历史回放不使用定时器。消费方保留现有进度事件格式，最终结果与取消时的输出仍可重建。

托管 npm 安装校验成功后原子发布新目录；取消保留旧安装。卸载仅针对当前托管版本，与捆绑和外部安装分开。旧版本目录保留供仍持有它们的其他进程使用。

SSH 在显式配置的 POSIX 主机上启动已安装适配器。启动数据通过 stdin 传递，严格检查主机密钥，会话可撤销的 HTTP MCP 端点经独立反向隧道连接。远程适配器不获得本机文件或终端回调。只有缺少 HTTP 能力的本地适配器才使用标准 stdio 桥接转发 HTTP MCP。

## 考虑过的替代方案

**把检测成功当作已连接。** 初始化不能证明活动会话存在，也不能证明账号能请求模型。分开记录可避免进程退出后仍显示过期连接状态。

**共享预热会话池。** Agentero 的预热会创建并关闭会话。复用真实项目会话会混淆外部身份、权限和 MCP 凭据；每会话独立进程保留清晰所有权。

**复制 Agentero 的状态框架或历史数据库。** 现有 Cordis 服务、slots、设置和会话日志已经拥有这些职责，引入另一套系统会重复生命周期和持久化规则。

**保存每次输出快照。** 单个快照的字节上限仍会重复保存不断增长的前缀，使会话存储成倍增加。状态变化和结束时写入保留完成依据，无需定时器或另一种增量格式。

## 结果

渠道目录让用户无需切换会话即可查看渠道可用情况。启动取消使更新的选择保持响应，原生 CLI 启动耗时仍明确展示。可选协议功能依赖适配器实际声明。远程运行需要已配置主机和已安装软件；文件同步和远程工作区浏览不属于本决策。
