# Agent Note：响应及时的 PaperAI Agent 与以文档为中心的工作台

状态：已实施

[English](2026-09-05-paperai-agentero-adoption.md) | 中文

## 问题

原生 Agent 初始化可能需要数秒，禁用整个输入区会使启动延迟妨碍写作。文档导航还需要明确的上下文来源和有界渲染，同时保留草稿。项目文件缺失需要可查看的恢复路径，且不能覆盖较新的工作。

## 决策

PaperAI 从所审阅的 [Agentero](https://github.com/poco-ai/Agentero/tree/7c5efcd1fbab0c5bd14969acdaa437912beb4b93) 架构中采用独立 Agent 诊断、即时显示待切换选择、显式文档引用、有界预览缓存和只读项目检查。这些能力通过 DSH 插件扩展点实现，仍以 Cordis、生成式 Remote API 和权威 DOCX 操作为基础，不依赖 Agentero 的 Tauri 进程、Zustand 存储或富文本正文模型。其预热会启动并关闭适配器会话，并不为 PaperAI 建立可复用进程池。

本决策部分取代 [PaperAI UI 决策](../feature/2026-09-03-paperai-ui-overhaul.zh.md)中的布局和草稿刷新行为，其模板、品牌和按块编辑决策继续有效。

## Agent 替换与诊断

选择后立即显示待切换名称。单一控制器串行执行 Host 替换，每次回执后处理最新待切换意图。意图属于操作时选中的 Session，导航不会将其应用到其他项目。失败时恢复最后成功的路由。作用域内的发送等待记录允许继续写草稿，同时阻止键盘和按钮发送，包括旧 Agent 移除期间。只有已连接适配器公告才能启用实时模型选择。

provider 拥有的诊断与对话句柄分离。发现阶段只读取安装信息，不创建进程。显式探测使用空临时目录，不携带提示词或 PaperAI MCP descriptor，拒绝客户端文件操作，并采用原生只读模式。并发探测共享工作，可配置限制约束初始化时间和失败重试，清理完成后才返回。缓存绑定精确启动配置，较新的真实会话优先于旧探测。缓存表示历史观察，不代表当前授权或实时可选模型。原生 CLI 启动延迟仍可观察，不以未经测量的提速承诺掩盖它。

切换操作持有 runtime 会话绑定租约，在 Host 替换完成前保留列表中的 Session 和浏览器作用域。租约维持导航与草稿身份，不授予发送权限；最后一份租约释放后会显露未完成的移除。

API 网关将模型读取、模型选择与预设替换按会话排序，替换完成后才解析实时 Agent。预设提交事件会刷新该 Session 已有的模型目录。文档导航沿用项目中已选中的 Session，打开 Word 不会替换既有对话或草稿。

## 文档工作区

通用布局通过校验后的配置允许文档位于对话之前。PaperAI 左侧为项目，中间为 Word，右侧为 Agent，Word 旁不显示起始介绍内容。窄窗口下询问选中文字会显示输入框，同时保留文档及其宽度偏好。

Word 选区成为可移除输入引用，包含精确文字、块 id、路径、文档 id、revision 和当前提交。异步发送前序列化并冻结可见上下文。既有 `user/message` 事件记录模型收到的相同文字；导航和诊断不增加隐藏上下文。产品文字呈现扩展显示引用，将来源信息收进可选展开区；复制内容和日志仍然完整。

预览缓存按配置限制数量，包含当前视图。淘汰预览时释放较重渲染内容，轻量滚动位置和草稿仍跨文档导航保留。外部变更使缓存失效。同一块变化时保留本地草稿供复制或取消，禁止覆盖替换后的块。DOCX 提交仍是唯一持久化编辑路径。

## 项目检查与恢复

项目体检读取已登记项目记录、原件、工作文件和保留快照，不执行初始化或修复。它报告文件缺失或变化、无效当前版本或快照、重复归属和不安全路径。只有工作文件缺失且所属当前提交已经验证时，才生成恢复候选方案。

恢复在提交服务的文档队列内执行，重新扫描核对方案，验证快照字节和目标路径祖先，然后通过原子且不覆盖的硬链接发布完整字节。当前提交变化或目标文件已存在都会拒绝方案。重新实体化已提交的当前版本不会新增内容版本，也不会伪造原件、覆盖外部修改或倒退历史。

## 影响

待切换选择与实际就绪状态分离。预览占用有界渲染内存，未保存文字仍是浏览器生命周期状态。诊断可以报告启动失败，但不能保证后续 provider 认证。恢复仅限于重建已验证的提交字节。

定向测试覆盖竞争选择、发送等待状态、探测超时和冷却、冻结引用、预览淘汰、过期读取与恢复拒绝。组装应用的无密钥浏览器快照覆盖初始化等待、Word 选区、草稿冲突以及独立的扫描、查看方案和恢复操作，并保留模型与权限流程。配置细节和限制由各包文档维护。

## 考虑过的替代方案

共享实时 ACP 进程池会跨项目耦合 Session 权限和已认证 MCP descriptor，因此对话句柄继续独立拥有进程。以 Tauri 和 Zustand 替换 DSH 会丢弃既有插件生命周期和生成 API，却不能减少原生适配器启动时间。扫描时自动恢复会隐藏文件修改，因此检查和显式恢复保持独立。
